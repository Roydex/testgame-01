- `cancel_time`：从出招开始计时，超过该时间后收招可被招架、格挡、冲刺、跳跃或技能取消。
- `next_attack`：光矛·刺 → 光矛·横扫 → 光矛·贯。在活动段结束前按下攻击键（缓冲 0.25 s）即可接续下一段。
- `vertical_track_*`：有限垂直追踪。在 `vertical_track_range` 高度差以内，按不超过 `vertical_track_speed` 的速度修正高度；超出这个高度差不追踪。
- 突进期间水平到达目标 2.2 m 内即停止前进，避免穿过目标或产生吸附感；垂直追踪继续，活动判定持续到活动段结束。
- 突进撞墙即停（`stop_on_wall`），不穿透掩体。
