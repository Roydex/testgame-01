## 5. 动作层（MechVisual，程序化占位动作）

每个招式定义两个关键姿势：前摇结束时、活动段结束时。

- **前摇**：从待机姿势以 ease-out 过渡到前摇姿势。有预兆的招式会附加轻微颤动。
- **活动段**：在前 40% 时间内迅速切到出击姿势。
- **收招**：以 ease-in 回到待机姿势。
- **顿帧**：期间姿势冻结，突出命中瞬间。

| 招式 | 前摇 → 出击 |
|---|---|
| 光矛·刺 / 裁决反击 | 后拉、躯干后转 → 前刺，光矛伸长到 1.45 倍 |
| 光矛·横扫 | 手臂向右展开 → 水平横扫到左侧 |
| 光矛·贯 | 下蹲、后仰、长距离后拉 → 前倾，光矛伸长到 1.8 倍 |
| 瞬时突进斩 | 低姿、矛尖朝后 → 向上挑斩 |
| 终审之矛 | 高举蓄力、光翼展开 → 全身前倾，光矛伸长到 2.3 倍 |
| 格挡 / 招架 | 镜盾举到胸前；招架窗口内镜盾高亮，招架成功时闪光 |
| 硬直 / 失衡 | 后仰下沉 / 大幅后仰、双臂甩开 |
| 受击 | 按受击方向施加弹簧后仰（弹性系数 140，阻尼 14） |
