# 平衡报告

**当前没有任何数值经过平衡验证。** 所有 `MechMovementProfile` 数值都是原型参数，标记为“待测试”。

本阶段只用自动化测试确认了以下几点：
- 5 套配置在机动指标上有可测差异（见 MOVEMENT_PARAMETERS.md §2），差异方向与 AGENT.md §10.3 的定位一致：
  - 白祷：高速、灵敏。
  - 赤狱：空中惯性大，悬停最弱（3.8 s）。
  - 苍藓：慢，但悬停最稳（7.8 s），制动强。
  - 苍穹：空中水平移动好，悬停次稳（6.2 s）。
- EN 规则能约束滞空：任何配置都无法无限滞空，冲刺会明显压缩滞空能力。

机体之间的强弱平衡需要等阶段 3（技能）和阶段 8（平衡）完成后，结合实战数据再评估。
