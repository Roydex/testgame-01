## 3. 人工验收清单（阶段 2b）

运行游戏后默认为**练习模式**：你和陪练机都不会阵亡，大招不限次数；陪练机按“单次出招 → 后撤”的节奏陪你练，你被硬直时它们不追击。两台陪练机同阵营，都以你为目标。

- `F9` / `F11`：切换近战 / 远程陪练机的模式。
- `F12`：切换到实战模式（会阵亡、大招每局一次、陪练机全力进攻、两台陪练机分属不同阵营）。
- `F5`：回满 HP / EN / 大招。
